# Assignment 1: Java Source Code vs. Bytecode

Java source code is the human-readable set of instructions that a programmer writes in a file ending in `.java`. For my Student Grade Calculator, the source code includes the student information, three assignment grades, the formula for the average, and the if/else statement that decides whether the student passed. Before the computer can execute it, the Java compiler (`javac`) checks the code and converts it into bytecode stored in a `.class` file. Bytecode is not the same thing as source code or ordinary machine code. Instead, it is an intermediate format designed for the Java Virtual Machine (JVM). When I use the `java` command, the JVM loads and runs that bytecode. This process helps make Java portable because the same compiled program can run on different operating systems that have compatible JVMs.
