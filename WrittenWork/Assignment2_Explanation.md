# Assignment 2: Classes, Objects, Attributes, and Methods

In my inventory application, the Product class works like a blueprint for the items a store sells. It defines the information each product needs and the actions it can perform. I created two Product objects, one for a mechanical keyboard and another for a gaming headset. Although they come from the same class, each object has its own name, price, and quantity. These values are attributes, and they are declared private so other classes cannot directly change them. This is an example of encapsulation. The constructor provides the starting values when each object is created. Methods make the objects useful: calculateInventoryValue() multiplies the price by the quantity, while getter methods provide safe access to product information. The InventoryApp class then uses those objects to calculate a combined total and display a report in the console and a graphical dialog. This separation keeps the code organized and reusable.
